# プロダクト要求

## 目的

`savorit` は、お気に入りのレシピを保存し、後から検索し、実際に作った記録を残すための個人向けアプリケーションである。

このプロダクトは、「以前作った料理を思い出したが、どのレシピだったかすぐに見つけられない」という問題を解決する。レシピそのものだけでなく、いつ作ったか、どのように作ったか、どの程度気に入っているかを後から見返せることを重視する。

## 対象ユーザー

主な対象ユーザーは、自宅で料理をし、自分用のレシピと調理履歴を長く保存したい個人である。

初期方針は個人利用優先とする。複数人共有や公開投稿は、MVPでは扱わない。

## MVPスコープ

MVPには以下を含める。

- ユーザー登録、ログイン、ログアウト、パスワードリセット、管理者ユーザー。
- ユーザーごとに分離されたレシピデータ。
- レシピの作成、編集、削除、詳細表示、一覧表示。
- キーワードによるレシピ検索。
- レシピタグ。
- 材料と手順。
- お気に入り登録と解除。
- 作った日、メモ、任意の画像を持つ調理記録。
- ローカルファイル保存によるレシピ画像。

MVPはブラウザで利用するアプリケーションとして使える状態を目標にする。ネイティブモバイルアプリはMVPに含めない。

## MVP対象外

MVPには以下を含めない。

- レシピの公開共有。
- 家族やグループでの共有。
- SNS的な機能。
- 買い物リスト。
- 栄養計算。
- AIによるレシピ生成。
- 外部URLからのレシピ自動取り込みや解析。
- ネイティブiOS / Androidアプリ。
- S3互換オブジェクトストレージを必須の実行環境にすること。

これらはMVPが安定した後に再検討する。

## プロダクト原則

- 保存したレシピは後から見つけやすくする。
- レシピ保存だけでなく、作った記録も同じくらい重視する。
- 検索や再利用に役立つ情報は、自由記述だけでなく構造化して保存する。
- 初期実装は完了可能な大きさに抑える。
- ただし、将来のスマートフォンアプリ展開を妨げない設計にする。
- 機能追加は開発フェーズに従って判断し、実装中の思いつきでスコープを広げない。

## 成功条件

MVPは、ユーザーが以下を実行できる状態を成功とみなす。

- アカウントを作成し、ログインできる。
- 材料、手順、タグ、画像を含むレシピを登録できる。
- 保存済みレシピをキーワードで検索できる。
- レシピをお気に入り登録できる。
- 特定の日にレシピを作った記録を残せる。
- 記憶に頼らず、後からレシピと調理履歴を見返せる。
